인게임 메뉴 → 공명자 → 속성 상세정보에서 스테이터스가 적혀 있는 곳을 캡처해 주세요.

에코 상세정보

세부 육성 창의 비어 있는 에코 칸에 에코가 추가됩니다.

인게임 메뉴 → 공명자 → 에코에서 등록할 에코의 옵션이 적혀 있는 곳을 캡처해 주세요.

육성 현황표

  • 육성 현황표의 스테이터스 칸에는 기본적으로 자세히 보기에 있는 스테이터스 값이 보여집니다.
  • 육성 현황표의 칸에 수치를 직접 입력하거나 속성 상세정보 이미지를 등록하면 해당 수치가 표시됩니다.
  • 입력한 수치를 지우면 다시 자세히 보기의 스테이터스 값으로 돌아갑니다.

데이터 저장과 백업

  • 파티 편성과 육성 정보는 현재 사용하는 브라우저에만 저장됩니다. 브라우저 캐시나 사이트 데이터를 지우면 사라집니다.
  • 상단의 내보내기로 백업 코드를 생성할 수 있습니다. 불러오기로 코드를 입력해 데이터를 불러올 수 있습니다.

참고 및 주의사항

  • 이름과 수치가 잘리거나 가려지지 않게 캡처해 주세요. 흐리거나 너무 작은 이미지는 인식되지 않을 수 있습니다.
  • 이미 입력된 정보가 있는 프리셋에 이미지를 등록하면 기존 정보가 사라지게 됩니다.
  • 잘못 읽힌 값은 저장한 뒤 세부 육성 창에서 직접 고칠 수 있습니다.
  • wuwa bot 프로필 카드의 무기 · 에코 정보를 통해 계산된 스테이터스 값에는 오차가 있을 수 있습니다. 정확한 수치가 필요하다면 속성 상세정보 이미지도 함께 올려 주세요. 육성 현황표에는 속성 상세정보 수치가 우선적으로 표시됩니다.

내보내기로 복사한 코드를 붙여넣어 주세요. 현재 데이터는 사라집니다.
