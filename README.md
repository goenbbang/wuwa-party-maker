# 공명자 관리기록부

명조(Wuthering Waves) 파티 편성 · 육성 기록 · 무기 도감 사이트.

## 폴더 구성
- `index.html` — 사이트 본체 (코드)
- `data/game-data.json` — 공명자 · 무기 · 에코 세트 · 회로 · 테마 데이터 (**수정은 여기만**)
- `images/` — 이미지 (WebP. 같은 이름의 `.png`를 올려도 자동으로 읽음)
- `assets/app.css` — 디자인(Tailwind) 미리 빌드한 파일. `index.html` 과 한 세트이니 같이 교체

## 데이터 수정 → 사이트 반영
1. 사이트 주소 뒤에 `?admin` 을 붙여 접속 → 관리자 모드 (이 브라우저에서 계속 유지, `?admin=off` 로 끔)
2. 오른쪽 위 편집기로 수정 (수정 내용은 이 브라우저에 임시 저장됨)
3. 아래 관리자 바의 **사이트 데이터 내보내기** → `game-data.json` 다운로드
4. GitHub 저장소 `data` 폴더 → **Add file → Upload files** → 파일 끌어다 놓기 → **Commit changes**
5. 1~2분 뒤 모든 방문자에게 반영

`game-data.json` 을 GitHub 웹에서 직접 열어 연필 아이콘으로 고쳐도 됩니다.

## 참고
- 일반 방문자에게는 편집기 · 설정 버튼이 보이지 않습니다. `?admin` 은 누구나 붙일 수 있지만, 그 사람 브라우저에서만 편집될 뿐 사이트 데이터는 바뀌지 않습니다 (GitHub에 올릴 수 있는 사람만 반영 가능).
- 보유 공명자 · 육성 기록은 방문자 각자의 브라우저에 저장됩니다.
- 이미지는 `images/` 폴더에 올리고 편집기에는 파일명만 입력하는 것을 권장합니다 (편집기에서 직접 업로드한 이미지는 데이터 파일에 통째로 들어가 파일이 커짐).
- `index.html` 을 더블클릭해서 열면 보안 정책 때문에 데이터를 못 읽습니다. 항상 사이트 주소로 접속하세요.
